Aturan Main PS3 HEN

  1. Penyewa wajib mengisi data diri yang sebenar-benarnya.
  2. DILARANG KERAS melakukan update sistem (System Update) via internet/flashdisk.
  3. DILARANG menghapus game, aplikasi (Multiman, dll), atau mengubah setting root.
  4. DILARANG login akun PSN sembarangan untuk menghindari banned.
  5. DILARANG membongkar, merusak segel baut, atau memodifikasi fisik console.
  6. Segala kerusakan fisik / sistem akibat kelalaian (jatuh, kena air, dsb) WAJIB DIGANTI RUGI sesuai nilai komponen.
  7. Keterlambatan waktu sewa (overtime) dikenakan biaya tambahan per jam.
  8. Kelengkapan wajib utuh saat kembali (Mesin, Stick, Kabel HDMI, Power, USB Charger).
  9. Data save game pribadi bukan tanggung jawab admin jika tertimpa/terhapus.
  10. Dilarang keras menyewakan ulang (sub-rental) unit ke pihak ketiga.
